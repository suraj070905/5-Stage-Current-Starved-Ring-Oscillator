# 5-stage-current-starved-ring-oscillator
A 180nm CMOS voltage-controlled oscillator achieving a 13x tuning range (23.6–302.5 MHz) using a current-starved ring oscillator topology. Designed and Simulated in Cadence Virtuoso.

## Overview

This project implements a 5-stage current-starved ring VCO, where the oscillation frequency is controlled by varying the bias current through each inverter delay stage. PMOS/NMOS current mirrors generate the bias current, while a 3-stage CMOS output buffer isolates the oscillator core from external loading and improves output drive capability.

## Features

- 180 nm CMOS technology
- Cadence Virtuoso implementation
- Five current-starved inverter delay stages
- PMOS/NMOS current-mirror biasing
- 3-stage CMOS output buffer
- Voltage-controlled frequency tuning

## Results

- Supply Voltage: 1.8 V
- Control Voltage Range: 0.5–1.8 V
- Frequency Range: 23.63 MHz – 302.5 MHz
